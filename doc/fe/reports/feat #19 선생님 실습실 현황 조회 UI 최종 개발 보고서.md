## 구현 요약

학생용 실습실 대여 신청 화면과 선생님용 실습실 현황 조회 화면을 분리했습니다. 선생님은 층별 실습실 예약 상태를 확인하고, 예약된 실습실 카드를 눌러 이용 상세를 조회할 수 있습니다. iOS 선생님 실습실 현황 화면의 정보 구조와 카드 비율을 Android Flutter UI에 맞게 적용했습니다.

## 구현된 기능

- [x] 선생님 계정 실습실 탭을 현황 조회 화면으로 연결
- [x] 4층·3층·2층 층 선택 세그먼트
- [x] 층별 실습실 카드와 예약 수 표시
- [x] 예약자·사용 목적·이용 유형 표시
- [x] 야자시간·방과후·미예약 상태 색상 구분
- [x] 예약 카드 상세 화면
- [x] 날짜·요일·이용시간·대여자·사용 목적·사용 위치 표시
- [x] 로딩·빈 상태·오류 상태 UI
- [x] 학생용 기존 실습실 대여 신청 흐름 유지
- [x] Notifier 상태 전환 테스트 추가
- [x] Material 아이콘 호환성 오류 수정
