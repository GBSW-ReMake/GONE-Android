## 구현 요약

학생이 실습실을 층별로 조회하고, 대여 신청을 작성한 뒤 신청 상태를 확인·취소할 수 있는 Android UI를 구현했습니다. 홈 대시보드의 실습실 탭과 연결해 로그인 이후 실제 흐름으로 확인할 수 있습니다.

## 구현된 기능

- [x] 4층·3층·2층 탭과 선택 가능한 실습실 목록
- [x] 선택한 실습실의 번호·수용 인원·빔프로젝터·예약 가능 상태 표시
- [x] 대표자·사용 인원·사용 목적 대여 신청 폼
- [x] 빈 입력 비활성 CTA, 최대 인원 검증, 다중 줄 한글·영문 입력
- [x] 신청 완료 후 내 실습실 대여 정보·진행 단계·취소·빈 상태
- [x] 홈 하단 실습실 탭과 화면 전환 연결
- [x] SVG 아이콘과 TalkBack 레이블 적용
