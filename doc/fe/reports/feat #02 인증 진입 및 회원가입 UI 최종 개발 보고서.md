## 구현 요약

GONE Android 앱의 첫 진입 경험을 구현했습니다. 사용자는 스플래시 화면 이후 학생 또는 선생님 역할을 선택하고, 로그인과 회원가입 흐름을 이용할 수 있습니다.

## 구현된 기능

- [x] GONE 로고 기반 스플래시와 Reduce Motion 대응
- [x] 학생·선생님 역할 선택과 하단 CTA
- [x] 로그인 입력 검증, 역할 선택으로 돌아가기, 회원가입 이동
- [x] 5단계 회원가입 입력 검증과 프로필 사진 선택
- [x] Riverpod 기반 인증 화면 전환 상태
- [x] 다크 모드, TalkBack 레이블, 48dp 터치 영역 적용
- [x] iOS 에셋과 제공한 역할 선택 일러스트 적용

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 역할 선택 일러스트 | iOS 에셋 재사용 | 개발자 제공 PNG로 교체 | 디자인 의도를 더 정확하게 반영하기 위함 |
| 회원가입 링크 | 안내 문장 전체 버튼 가능 | `회원가입`만 버튼 처리 | 오작동을 줄이고 링크 대상을 명확히 하기 위함 |
