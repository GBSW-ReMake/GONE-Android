## 구현 요약

Android 홈에 있던 알림 아이콘을 실제 알림 조회 화면과 연결했습니다. 학생과 선생님 역할에 따라 서로 다른 Mock 알림을 표시하고, iOS 알림 화면과 동일한 오늘·어제·최근 7일 구조, 알림 이미지·제목·설명·시각 정렬을 적용했습니다.

## 구현된 기능

- [x] 홈 알림 아이콘 탭 시 알림 화면 이동
- [x] 학생·선생님 역할별 알림 데이터 분리
- [x] 오늘·어제·최근 7일 그룹 표시
- [x] 캠핑·외출·상점·벌점·실습실 이미지 적용
- [x] 모두 읽음 처리
- [x] 홈 읽지 않은 알림 빨간 점 표시
- [x] 알림 로딩·빈 상태·오류 상태
- [x] 뒤로가기와 주요 Semantics 레이블
- [x] Repository·Notifier·Model 책임 분리
- [x] 역할별 알림·그룹화·읽음 처리 테스트

## 알려진 제한사항

- 알림 데이터는 현재 Mock Repository를 사용합니다.
- 서버 timestamp, 읽음 상태 저장, 푸시 알림 수신은 API/푸시 계약 후 연결해야 합니다.
- Flutter analyze에서 기존 PointSystem 화면의 정보성/deprecated 경고 4건이 남아 있습니다.
- 에뮬레이터/실기기에서 학생·선생님 각각의 알림 화면과 홈 배지를 확인해야 합니다.
- 기존 작업 트리의 `assets/images/outing-apply-illustration.png` 삭제 변경은 이번 기능 커밋에 포함하지 않았습니다.
