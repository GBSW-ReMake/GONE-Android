# 학생·선생님 알림 조회 UI 계획서

> **상태**: 계획서 검토 대기
> **작성일**: 2026-08-24
> **작업 번호**: 이슈 생성 후 확정
> **관련 이슈**: 계획서 검토 후 생성
> **브랜치**: 이슈 생성 후 `feat/<이슈번호>-notification-ui`로 분기

## 1. 목적 및 배경

현재 Android에는 홈 헤더의 알림 아이콘만 있고 알림 목록 화면과 역할별 알림 데이터가 구현되어 있지 않습니다. iOS에서 구현한 알림 화면을 기준으로 학생과 선생님이 자신의 역할에 맞는 알림을 날짜 그룹별로 확인할 수 있도록 Android Flutter 화면을 추가합니다.

학생 화면과 선생님 화면은 같은 화면 구조를 사용하되, 알림 제목·설명·아이콘·대상 데이터는 역할별로 구분합니다.

## 2. 사용자 시나리오

```text
사용자가 홈 헤더의 알림 아이콘을 누른다
→ 알림 화면으로 이동한다
→ 오늘·어제·최근 7일 그룹별 알림을 확인한다
→ 알림 제목·설명·발생 시각을 확인한다
→ '모두 읽음'을 누르면 읽지 않은 알림 상태가 해제된다
→ 뒤로가기로 홈 화면으로 돌아온다
```

## 3. 역할별 알림 범위

### 학생 알림

- 스쿨캠핑 예약 오픈
- 외출 신청 승인
- 상점 발급
- 벌점 발급
- 실습실 대여 승인
- iOS 학생 화면과 동일하게 캠핑·외출·상벌점·실습실 이미지를 사용합니다.

### 선생님 알림

- 학생 스쿨캠핑 신청
- 스쿨캠핑 예약 오픈
- 학생 외출 신청
- 학생 실습실 대여 신청
- 선생님 화면에서는 학생명·학년/반·신청 인원·이용 시간 등 교사 확인에 필요한 요약 정보를 설명에 포함합니다.
- 상점·벌점 발급 결과 알림은 학생용 데이터로 구분하고 선생님 화면에는 표시하지 않습니다.

## 4. 화면 및 UX

### 알림 목록 화면

- 흰색 배경과 SafeArea를 사용하고 iOS 화면과 유사한 좌우 여백·상단 여백을 적용합니다.
- 상단에는 48dp 터치 영역의 뒤로가기, 가운데 `알림` 제목, 오른쪽 `모두 읽음` 버튼을 배치합니다.
- 날짜 그룹은 `오늘`, `어제`, `최근 7일` 순서로 표시합니다.
- 알림 행은 왼쪽 56~64dp 이미지 영역, 가운데 제목·설명, 오른쪽 상대 시각/날짜로 구성합니다.
- 제목은 진한 네이비, 설명과 읽은 시각은 회색, 최근 알림 시각은 GONE 블루로 표현합니다.
- 긴 설명은 화면 너비에 맞춰 최대 2줄까지 표시하고 행 사이 간격을 iOS 기준으로 맞춥니다.
- 읽지 않은 알림은 상태 모델로 관리하며, 모두 읽음 동작 후 시각·스타일을 읽은 상태로 갱신합니다.
- 알림이 없을 때는 아이콘과 안내 문구가 있는 빈 상태를 표시합니다.

### 홈 알림 아이콘

- 기존 `assets/icons/bell.svg`를 유지합니다.
- 알림 화면으로 이동하도록 탭 동작을 연결합니다.
- 읽지 않은 알림이 있으면 iOS와 동일한 빨간 원형 배지와 흰색 숫자를 표시합니다.
- 읽지 않은 알림이 없으면 배지를 숨깁니다.
- 배지 숫자가 99를 초과하면 `99+`로 표시합니다.

## 5. 데이터 및 아키텍처

```text
features/notification/
├── domain/
│   └── notification.dart
├── application/
│   └── notification_notifier.dart
├── data/
│   ├── notification_repository.dart
│   └── mock_notification_repository.dart
└── presentation/
    └── notification_page.dart
```

- `NotificationItem`은 id, role, type, title, description, timestamp, image asset, read 상태를 가집니다.
- `NotificationGroup`은 현재 날짜 기준으로 오늘·어제·최근 7일을 계산해 목록을 그룹화합니다.
- `NotificationType`으로 캠핑·외출·상점·벌점·실습실 유형을 구분합니다.
- `NotificationRepository`를 통해 역할별 알림을 조회하고, 초기 구현은 Mock Repository를 사용합니다.
- `NotificationNotifier`는 역할, 목록, 읽음 상태, 로딩·빈·오류 상태를 관리합니다.
- 홈은 알림 화면의 읽지 않은 개수만 구독하고, 화면 이동과 배지 표시만 담당합니다.
- View에는 역할 판별·그룹 계산·읽음 비즈니스 로직을 직접 작성하지 않습니다.

## 8. 제한사항 및 결정 필요 항목

- 실제 알림 API와 서버의 읽음 처리 계약이 확정되지 않아 초기 구현은 Mock Repository를 사용합니다.
- 알림 시간은 서버 timestamp 연동 전까지 고정 샘플 데이터로 표시합니다.
- 이미지 에셋은 현재 Android 프로젝트에 추가된 `home-camping.png`, `home-outing.png`, `home-lab.png`, `point-plus.png`, `point-check.png`를 재사용합니다.
- 푸시 알림 수신 및 백그라운드 알림 처리는 이번 UI 범위에서 제외합니다.
