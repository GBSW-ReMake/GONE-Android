# 교사 상벌점 발급 UI 계획서

> **작업 번호**: #09

> **브랜치**: `feat/17-point-system`

## 1. 목적 및 배경

교사 계정의 기존 하단 `스쿨캠핑` 탭을 `상벌점` 탭으로 교체하고, iOS에 구현된 상벌점 발급 흐름과 동일한 기능을 Android Flutter 앱에 제공합니다.

- 학생 계정은 기존 스쿨캠핑 탭과 기능을 유지합니다.
- 교사 홈의 기존 프로필 정보는 유지하며, 교사에게만 상벌점 발급 기능을 노출합니다.
- 제공된 iOS 시안과 기존 Android 디자인 시스템의 간격·색상·카드 비율을 함께 적용합니다.

## 2. 사용자 시나리오

```text
교사 로그인
→ 하단 상벌점 탭 진입
→ 발급 대상자 추가
→ 학생 검색 및 선택
→ 학생별 상점/벌점, 발급 항목, 메모 작성
→ 명단에 저장
→ 여러 학생의 명단을 확인·수정·삭제
→ 점수 발급
→ 완료 화면에서 발급 명단 확인
→ 발급 내역/개인 통계 확인
```

## 3. 화면 및 UX

### 3.1 교사 하단 탭

- `HomePage`에 로그인 역할을 전달합니다.
- 학생: `홈 · 실습실 · 외출 · 스쿨캠핑 · 마이`를 유지합니다.
- 교사: `홈 · 실습실 · 외출 · 상벌점 · 마이`를 표시합니다.
- 기존 하단 탭의 선택 상태, 터치 영역, 아이콘 크기와 동일한 규칙을 사용합니다.

### 3.2 점수 발급

- 탭: `점수발급 · 발급 내역 · 통계`
- 빈 상태: 플러스 아이콘, 안내 문구, 전체 터치 가능한 대상자 추가 버튼, 비활성 발급 버튼
- 학생 검색: 학번 또는 이름 검색, 학생 선택 후 전체 화면 폼으로 전환
- 학생별 폼: 상점/벌점 선택, 발급 항목, 최대 3줄 메모, 명단 추가 버튼
- 명단: 카드 전체 터치 시 해당 학생의 기존 작성 내용을 수정하고, X 버튼은 삭제만 수행
- 발급: 명단 전체를 한 번에 발급하고 체크 아이콘 완료 화면을 표시

### 3.3 발급 내역 및 통계

- 발급 내역: `전체 · 상점 · 벌점` 필터, 한국어 날짜 표기
- 통계: 현재 로그인한 교사 기준의 발급 건수·상점·벌점 수치
- 통계 카드는 최종 iOS 시안의 낮고 밀도 있는 비율을 Android 화면 밀도에 맞춰 적용

### 3.4 상태 및 접근성

- 정상, 빈 상태, 학생 검색 결과 없음, 발급 항목 미선택, 발급 실패 상태를 제공합니다.
- 메모 외 영역 탭 시 키보드를 내립니다.
- TalkBack 설명과 최소 48dp 터치 영역을 보장합니다.

## 4. 데이터 및 아키텍처

기존 Flutter + Riverpod 패턴을 따릅니다.

- Domain: `PointStudent`, `PointIssueDraft`, `PointIssueRecord`, `PointKind`, `PointStatistics`
- Application: `PointSystemNotifier`가 명단, 학생별 초안, 발급 내역, 개인 통계를 관리
- Presentation: 화면은 상태 렌더링과 사용자 이벤트 전달에 집중
- 데이터: 현재 프로젝트의 mock 데이터 구조를 우선 사용하며, 실제 API 계약 확정 전까지 로컬 발급 기록으로 동작
- 자산: 기존 전달된 플러스·체크·상벌점 탭 아이콘을 Android `assets/`에 등록
