# 외출 신청 및 진행 UI 계획서

> **상태**: 구현 중
> **작성일**: 2026-08-17
> **작업 번호**: #06
> **관련 이슈**: [#11](https://github.com/GBSW-ReMake/GONE-Android/issues/11)
> **브랜치**: `feat/11-outing-flow`

## 1. 목적 및 배경

학생이 외출 날짜·시간·담당 선생님·사유를 입력해 외출을 신청하고, 승인 상태와 외출 진행 상태를 한 흐름에서 확인할 수 있도록 구현합니다. 승인 후에는 길게 누르는 조작으로 외출 시작과 종료를 명확히 처리하며, 위치 공유가 필요한 상태를 사용자에게 안내합니다.

## 2. 사용자 시나리오

```text
사용자가 하단 외출 탭을 선택한다
→ 외출 신청 버튼을 눌러 신청 폼으로 이동한다
→ 날짜, 점심·저녁·직접 설정 시간, 담당 선생님, 사유를 입력한다
→ 외출 신청 후 승인 요청 카드와 상세 화면을 확인·수정·취소한다
→ 담당 선생님 승인 상태가 반영되면 외출 대기 화면으로 전환된다
→ 사용자가 1.5초간 길게 눌러 외출을 시작하고 위치 공유 상태를 확인한다
→ 1.5초간 길게 눌러 복귀 처리하면 외출 신청 초기 화면으로 돌아간다
```

## 3. 화면 및 UX

### 외출 신청 초기 화면

- 현재 신청 가능한 기간·시간 안내와 외출 일러스트를 표시합니다.
- 승인 요청 중인 외출은 요약 카드로 노출하며, 카드를 누르면 외출 상세 화면으로 이동합니다.
- 신청 내역이 없으면 `외출 신청` CTA를 제공합니다.

### 외출 신청·수정 폼

- 외출 날짜 선택 필드와 점심·저녁·직접 설정 시간 선택을 제공합니다.
- 점심 시간은 **12:30–13:30**, 저녁 시간은 **18:10–19:10**으로 자동 입력합니다.
- 직접 설정은 출발·복귀 시간을 Time Picker로 선택하며, 복귀 시간이 출발 시간보다 늦은지 검증합니다.
- 담당 선생님 선택은 스쿨캠핑과 같은 검색 바텀시트 방식을 재사용합니다.
- 외출 사유는 여러 줄 텍스트 입력으로 제공하고, 날짜·시간·선생님·사유 입력 전에는 CTA를 비활성화합니다.
- 수정 화면은 기존 신청 값을 채우고, 승인 대기 상태에서만 수정·취소할 수 있습니다.

### 신청 완료·상세

- 신청 완료 카드에 상태(승인 요청), 날짜, 시간, 사유, 담당 선생님을 표시합니다.
- 카드를 누르면 학적 정보, 외출 일정, 사유, 지정 선생님이 담긴 상세 화면으로 진입합니다.
- 승인 전에는 신청 취소와 수정 진입을 제공하고, 승인 후에는 변경 불가 안내를 표시합니다.

### 승인·외출 진행

- 외출 상태는 `승인 대기 → 외출 대기 → 외출 중 → 복귀 대기 → 종료`로 표시합니다.
- 외출 시작·종료 버튼은 **1.5초 길게 누르기**로만 실행되며, 원형 진행 표시와 진동 피드백을 제공합니다.
- 외출 중에는 남은 시간과 `현재 위치와 이동 경로를 선도부 학생에게 공유 중` 안내를 표시합니다.
- 복귀 시간이 가까워지면 경고 색상과 남은 시간을 표시합니다.
- 외출 종료 성공 시 상태를 정리하고 외출 신청 초기 화면으로 되돌립니다.

### 상태·접근성

- 승인 대기·거절·승인·권한 거부·위치 공유 실패·네트워크 오류·신청 내역 없음 상태를 구분합니다.
- 길게 누르기 버튼에는 남은 누름 시간과 실행 결과를 TalkBack 알림으로 제공합니다.
- 핵심 조작은 48dp 이상 터치 영역, 키보드 표시 시 폼 스크롤, 색상 외 텍스트 상태 표시를 보장합니다.

## 4. 데이터 및 아키텍처

```text
features/outing/
├── domain/
│   ├── outing_request.dart
│   ├── outing_time_slot.dart
│   └── outing_status.dart
├── application/
│   └── outing_notifier.dart
└── presentation/
    ├── outing_page.dart
    ├── outing_form_page.dart
    ├── outing_detail_page.dart
    ├── outing_progress_page.dart
    └── widgets/
```

- `OutingRequest`, `OutingTimeSlot`, `OutingStatus`, `Teacher` Entity로 외출 상태를 표현합니다.
- `OutingNotifier`는 화면 전환, 폼 검증, 신청·수정·취소, 승인 결과, 길게 누르기 진행 상태를 관리합니다.
- 선생님 검색 목록과 승인 전환은 UI 단계에서 목 데이터로 구현합니다. 실제 승인 결과는 이후 Repository·UseCase를 통해 서버 이벤트로 반영합니다.
- 길게 누르기 진행은 View가 제스처·진동 전달을 담당하고, 상태 전환 규칙은 Notifier/UseCase로 분리합니다.
- 실제 위치 공유는 Android 위치 권한, 명시적 동의, Foreground Service, 서버의 선도부 수신 권한과 보관 정책이 필요합니다. 이번 UI 작업에서는 **권한 안내·공유 상태 UI·목 위치 상태**까지만 구현하며, 실시간 위치 전송은 API·정책 확정 후 별도 작업으로 분리합니다.
