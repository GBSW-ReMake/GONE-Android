# 스쿨캠핑 예약 UI 계획서

> **상태**: 완료
> **작성일**: 2026-08-16
> **작업 번호**: #05
> **관련 이슈**: [#9](https://github.com/GBSW-ReMake/GONE-Android/issues/9)
> **브랜치**: `feat/9-camping-reservation`

## 1. 목적 및 배경

학생이 원하는 날짜를 달력에서 선택하고, 담당 선생님과 참여 학생을 검색해 스쿨캠핑 예약을 신청한 뒤 예약 상태를 확인할 수 있는 UI를 구현합니다. 제공된 iOS 시안의 예약 흐름과 검색 바텀시트 UX를 Flutter Android에 적용합니다.

## 2. 사용자 시나리오

```text
사용자가 하단 스쿨캠핑 탭을 선택한다
→ 월간 달력에서 예약 가능한 날짜를 선택한다
→ 선택한 날짜의 예약 폼으로 이동한다
→ 담당 선생님과 학생을 검색해 참여 명단에 추가한다
→ 예약하기를 눌러 예약 신청 완료 카드를 확인한다
→ 달력 보기 또는 내 예약으로 돌아간다
```

## 3. 화면 및 UX

### 예약 달력

- 상단에 스쿨캠핑 제목, 내 예약 진입 버튼, `원하는 날짜를 선택하세요` 안내를 표시합니다.
- 이전·다음 달 이동과 월간 달력을 제공합니다.
- 예약 가능·내 예약·예약 불가 날짜를 구분해 표시합니다.
- 예약 가능한 날짜를 누르면 예약 폼으로 이동합니다.

### 예약 폼

- 선택한 날짜를 요약하고 담당 선생님 검색 필드를 제공합니다.
- 학생은 검색 바텀시트에서 학번 또는 이름으로 조회해 추가합니다.
- 추가된 학생·선생님은 칩으로 표시하며 개별 삭제할 수 있습니다.
- 최대 참여 인원(8명)과 본인 포함 여부를 표시합니다.
- 필수 값(날짜·담당 선생님·참여 학생)을 모두 충족하기 전에는 예약 버튼을 연한 파란색 비활성 상태로 표시합니다.

### 예약 신청 완료

- 예약 완료 배지, 날짜, 담당 선생님, 대표 학생, 참여 인원, 예약 상태를 카드로 제공합니다.
- 참여 명단 확인·수정과 예약 취소 UI를 제공합니다.
- 달력에서 예약한 날짜가 내 예약 상태로 표시됨을 안내합니다.

### 공통 UX

- 하단 탭은 기존 SVG 아이콘을 재사용하고 스쿨캠핑 탭을 선택 상태로 표시합니다.
- 검색·날짜·칩 삭제·예약·취소는 48dp 이상의 터치 영역과 TalkBack 레이블을 제공합니다.
- 키보드가 열렸을 때 폼이 스크롤되도록 구성합니다.

## 4. 데이터 및 아키텍처

```text
features/camping_reservation/
├── domain/
│   ├── camping_reservation.dart
│   └── participant.dart
├── application/
│   └── camping_reservation_notifier.dart
└── presentation/
    ├── camping_calendar_page.dart
    ├── camping_reservation_form_page.dart
    ├── camping_reservation_complete_page.dart
    └── widgets/
```

- `CampingDate`, `CampingReservation`, `Participant`, `ParticipantRole` Entity를 사용합니다.
- `CampingReservationNotifier`가 선택 날짜·화면·검색어·담당 선생님·참여 학생·예약 상태를 관리합니다.
- 초기 UI 단계에서는 목 데이터로 검색과 예약 흐름을 구현합니다.
- API 계약 후 Repository와 UseCase로 날짜별 가능 여부·교사 검색·학생 검색·예약·취소를 분리합니다.
- 예약 완료 화면은 **스쿨캠핑 예약 신청 완료** 카드로 구현합니다. 요청 문구의 `외출 신청 완료`는 스쿨캠핑 흐름에 맞춰 예약 완료로 해석합니다.
