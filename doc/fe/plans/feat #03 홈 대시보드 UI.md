# 홈 대시보드 UI 계획서

> **상태**: 완료
> **작성일**: 2026-08-13
> **작업 번호**: #03
> **관련 이슈**: [#5](https://github.com/GBSW-ReMake/GONE-Android/issues/5)
> **브랜치**: `feat/5-home-dashboard`

## 1. 목적 및 배경

GONE Android 앱에서 학생이 오늘 시간표와 급식, 월별 학사일정, 주요 신청 상태를 한 화면에서 확인하도록 홈 대시보드를 구현합니다.

## 2. 사용자 시나리오

```text
사용자가 하단 홈 탭을 선택한다
→ 오늘 시간표와 급식 카드를 좌우로 넘겨 확인한다
→ 이전·다음 달 버튼으로 학사일정을 확인한다
→ 실습실·외출·스쿨캠핑 신청 현황을 확인한다
→ 하단 탭으로 각 기능의 후속 화면에 이동한다
```

## 3. 화면 및 UX

- 상단: GONE 로고와 학생 요약 카드
- 시간표·급식: `PageView` 기반 수평 스와이프와 현재 페이지 표시
- 학사일정: 월 이동 버튼, 일정 목록, 일정이 없는 달의 빈 상태
- 신청 현황: 실습실·외출·스쿨캠핑 카드와 제공한 일러스트·상태 배지
- 하단 탭: 홈, 실습실, 외출, 스쿨캠핑, 설정. 이번 단계에서 홈 외 탭은 준비 중 안내를 표시합니다.
- 각 탭은 48dp 이상 터치 영역과 TalkBack 레이블을 제공합니다.

## 4. 데이터 및 아키텍처

```text
features/home/
├── domain/
│   └── entities/home_dashboard.dart
├── application/
│   └── home_dashboard_notifier.dart
└── presentation/
    ├── home_page.dart
    └── widgets/
```

- 초기 버전은 화면 검토용 목 데이터로 구성합니다.
- `HomeDashboardNotifier`가 표시할 월과 선택된 하단 탭을 관리합니다.
- 실제 시간표·급식·학사일정·신청 API 계약이 확정되면 Repository와 UseCase를 추가합니다.
