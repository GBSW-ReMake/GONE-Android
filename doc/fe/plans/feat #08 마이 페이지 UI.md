> **브랜치**: `feat/15-my-page`

## 목적

기존 하단 `설정` 탭을 `마이` 탭으로 전환하고, 계정 정보·알림 설정·문의하기·최근 활동·로그아웃을 한 화면에서 확인할 수 있는 마이 페이지를 구현합니다.

## 사용자 흐름

```text
하단 마이 탭 선택
→ 계정 및 최근 활동 확인
→ 전체/실습실/외출/스쿨캠핑 필터 선택
→ 활동 카드의 종류와 맞는 아이콘·내용 확인
→ 로그아웃 선택 및 확인
→ 역할 선택 화면으로 이동
```

## 구현 범위

- 하단 탭 레이블을 `설정`에서 `마이`로 변경하고 제공된 사용자 SVG 아이콘을 적용합니다.
- 계정 카드, 알림 설정·문의하기 메뉴의 안내 피드백을 구현합니다.
- 홈 신청 현황과 동일한 실습실·외출·스쿨캠핑 이미지로 최근 활동 카드를 구성합니다.
- 전체/실습실/외출/스쿨캠핑 필터로 최근 활동 목록을 즉시 변경합니다.
- 로그아웃 확인 다이얼로그 후 인증 진입 화면으로 복귀합니다.

## 아키텍처

- `features/my/application`: 필터 상태와 로그아웃 화면 이벤트를 관리합니다.
- `features/my/domain`: 활동 유형과 활동 표시 모델을 정의합니다.
- `features/my/presentation`: 마이 페이지와 활동·필터 UI를 담당합니다.
- 기존 `AuthFlowNotifier`에 로그인 상태 해제 전환을 명확한 메서드로 추가합니다.
