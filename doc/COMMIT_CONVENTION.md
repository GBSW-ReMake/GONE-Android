# GONE Android 커밋 메시지 규칙

## 형식

```text
타입: 제목 (#이슈번호)
```

| 타입 | 용도 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `ui` | 기능 변경 없는 UI 수정 |
| `refactor` | 기능 변경 없는 구조 개선 |
| `test` | 테스트 추가·수정 |
| `docs` | 문서 추가·수정 |
| `chore` | 설정·도구·의존성 변경 |
| `hotfix` | 운영 긴급 수정 |

- 제목은 한국어, 50자 이내, 마침표 없이 작성합니다.
- 하나의 커밋에는 하나의 논리적 변경만 담습니다.
- 기능과 수정 커밋에는 관련 이슈 번호를 포함합니다.

```text
docs: Android 개발 문서 체계 추가
feat: 로그인 입력 검증 추가 (#12)
```
