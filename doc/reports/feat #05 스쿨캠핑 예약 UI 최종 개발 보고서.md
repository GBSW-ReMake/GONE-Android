## 구현 요약

학생이 스쿨캠핑 탭에서 날짜를 선택하고, 담당 선생님·참여 학생을 검색으로 추가해 예약을 신청한 뒤 완료 내역을 확인할 수 있는 목 데이터 기반 UI 흐름을 구현했습니다.

## 구현된 기능

- 월간 달력 및 이전·다음 달 이동
- 날짜 선택 후 예약 폼 전환
- 선생님·학생 이름 또는 학번 검색 바텀시트
- 참여 학생 추가·삭제와 최대 8명 제한
- 필수 입력 전 예약 버튼 비활성화
- 예약 신청 완료 카드, 내 예약 조회, 예약 취소
- 예약된 날짜의 `예약됨` 배지와 재예약 비활성화
- 홈 하단 스쿨캠핑 탭 연결
- 예약 상태 전환 Riverpod 단위 테스트

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 예약 상태 표시 | 예약 가능·내 예약·예약 불가 구분 | 내 예약 날짜에 `예약됨` 배지와 탭 비활성화 추가 | 예약 완료 날짜의 중복 예약 방지 요구 반영 |
| 담당 선생님 표시 | 선택 후 참여자 칩 표시 | 검색 필드에 선택된 선생님 이름만 표시 | 불필요한 보조 ID 뷰를 제거해 시안과 일치 |
| 참여자 칩 | 참여자 정보 표시 | `인원 추가` 버튼과 동일한 44dp 높이로 통일 | 가독성과 레이아웃 밀도 개선 |
