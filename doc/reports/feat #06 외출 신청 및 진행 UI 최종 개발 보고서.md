# 외출 신청 및 진행 UI 최종 개발 보고서

> **완료일**: 2026-08-17  
> **작업 번호**: #06  
> **관련 이슈**: [#11](https://github.com/GBSW-ReMake/GONE-Android/issues/11)  
> **브랜치**: `feat/11-outing-flow`

## 구현 내용

- 외출 탭에 신청 안내, 외출 일러스트, 신청 CTA 및 승인 요청 요약 카드를 구현했습니다.
- 날짜·점심·저녁·직접 시간 선택, 선생님 검색 바텀시트, 사유 입력과 필수값 검증을 구현했습니다.
  - 점심: 12:30–13:30
  - 저녁: 18:10–19:10
- 신청 내역 상세, 수정, 취소 및 목 승인 전환 흐름을 추가했습니다.
- 외출 대기·시작·외출 중·복귀 상태를 1.5초 길게 누르기와 햅틱 피드백으로 전환하도록 구현했습니다.
- 외출 중 위치·이동 경로 공유 안내 UI를 추가하고, 모든 외출 화면을 공통 하단 탭과 연결했습니다.

## 구조 및 품질

- `domain`: 외출 요청, 상태, 시간 범위를 모델링했습니다.
- `application`: `OutingNotifier`가 폼 검증과 신청·취소·상태 전환을 관리합니다.
- `presentation`: 신청, 상세, 진행 상태 화면을 분리해 UI 책임을 유지했습니다.
- 상태 전환과 시간 범위를 단위 테스트로 검증했습니다.

## QA 결과

- `flutter analyze` 통과
- `flutter test` 통과
- `flutter build apk --debug` 통과
- Android 에뮬레이터에서 신청 → 상세 → 목 승인 → 길게 눌러 외출 시작/종료 → 초기 화면 복귀 흐름을 확인했습니다.

## 알려진 제한 사항

- 선생님 검색 및 승인 결과는 UI 검증용 목 데이터입니다.
- 위치 공유는 안내 UI와 목 상태만 구현했습니다. 실제 전송은 위치 권한·명시적 동의·Foreground Service·서버 수신/보관 정책 확정 후 별도 작업으로 진행해야 합니다.
