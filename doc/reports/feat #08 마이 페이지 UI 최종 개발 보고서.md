# 마이 페이지 UI 최종 개발 보고서

> **완료일**: 2026-08-18  
> **작업 번호**: #08  
> **관련 이슈**: [#15](https://github.com/GBSW-ReMake/GONE-Android/issues/15)  
> **브랜치**: `feat/15-my-page`

## 구현 내용

- 하단 다섯 번째 탭을 `설정`에서 `마이`로 변경하고 제공된 사용자 SVG를 적용했습니다.
- 계정 정보 카드, 알림 설정·문의하기 메뉴와 안내 피드백을 구현했습니다.
- 최근 활동을 전체/실습실/외출/스쿨캠핑 필터로 분류해 즉시 표시하도록 구현했습니다.
- 활동 카드에는 홈 신청 현황의 실습실·외출·스쿨캠핑 일러스트를 동일하게 재사용했습니다.
- 로그아웃 확인 다이얼로그 후 역할 선택 화면으로 복귀하도록 인증 흐름을 연결했습니다.

## 구조

- `features/my/domain/my_activity.dart`: 활동 유형·필터·목 활동 데이터를 정의합니다.
- `features/my/presentation/my_page.dart`: 계정, 메뉴, 활동 필터 및 로그아웃 UI를 담당합니다.
- `AuthFlowNotifier.logout()`: 인증 화면 전환을 한 곳에서 관리합니다.

## QA 결과

- `flutter analyze` 통과
- `flutter test` 통과 (13개)
- `flutter build apk --debug` 통과
- 활동 필터와 로그아웃 확인 흐름을 위젯 테스트로 검증했습니다.

## 참고

- 알림 설정과 문의하기는 화면 진입 안내 UI까지 구현했으며, 실제 알림 권한·문의 채널 연동은 API/정책 확정 후 연결이 필요합니다.
